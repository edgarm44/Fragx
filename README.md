# Fragx

Site web gratuit pour les joueurs de jeux de tir (Valorant, Fortnite, Apex Legends, Call of Duty, Battlefield) : évaluation et amélioration du setup, benchmark navigateur, réglages in-game, entraînement de visée, statistiques et guides.

Stack prévue : [Astro](https://astro.build).

Voir [CAHIER_DES_CHARGES.md](CAHIER_DES_CHARGES.md) pour le périmètre détaillé.
