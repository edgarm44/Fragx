EA publie lui-même une liste de réglages conseillés pour jouer en compétition sur PC. Les voici, dans l'ordre du menu **Paramètres > Vidéo** (les noms peuvent varier légèrement selon la langue du jeu).

## Vidéo

| Option | Réglage | Pourquoi |
|---|---|---|
| Mode d'affichage | Plein écran (fenêtré si tu utilises plusieurs écrans) | La latence la plus faible |
| Format et résolution | Ceux de ton écran | Image nette, sans déformation |
| Luminosité | Un peu plus haute que par défaut | Les adversaires dans les zones sombres sont plus visibles |
| Champ de vision (FOV) | Entre 90 et 110 | Vue plus large ; 110 est très répandu chez les joueurs compétitifs |
| Tremblement en sprint | Minimal | Image plus stable en mouvement |

## Vidéo avancée

| Option | Réglage |
|---|---|
| Synchronisation verticale | Désactivée (à activer seulement si l'image se déchire) |
| NVIDIA Reflex | Activé (carte NVIDIA) |
| Résolution adaptative (cible FPS) | Désactivée, sauf si les FPS chutent souvent |
| Anticrénelage | Aucun |
| Budget de streaming des textures | Bas ou moyen |
| Filtrage des textures | Bilinéaire |
| Occlusion ambiante | Désactivée |
| Couverture et détail des ombres du soleil, détail des ombres ponctuelles | Bas |
| Éclairage volumétrique, ombres ponctuelles dynamiques | Désactivés |
| Détail des modèles, des effets, ragdolls | Bas |
| Marques d'impact | Bas ou désactivées |

Ces réglages libèrent des ressources pour garder un nombre d'images par seconde élevé et régulier pendant les combats, là où ça compte.
