Fortnite propose un **mode de rendu Performance** pensé pour le jeu compétitif : c'est le réglage qui change le plus les choses sur un PC moyen. Les options se trouvent dans **Échap > roue crantée > Vidéo** ; les noms peuvent varier légèrement selon la langue du jeu.

## Affichage

| Option | Réglage | Pourquoi |
|---|---|---|
| Mode fenêtre (Window Mode) | Plein écran | Réduit la latence d'entrée |
| Résolution | Native de ton écran | Beaucoup de joueurs compétitifs restent en 1920 × 1080 |
| Synchronisation verticale | Désactivé | Ajoute de la latence ; un écran FreeSync ou G-Sync évite les déchirures |
| Mode de rendu (Rendering Mode) | Performance | Désactive la plupart des effets lourds et allège le processeur et la carte graphique |
| Limite d'images par seconde | Illimitée, ou fréquence de l'écran si l'image se déchire | Laisse le jeu produire le maximum d'images |

## Qualité graphique (en mode Performance)

| Option | Réglage | Pourquoi |
|---|---|---|
| Distance d'affichage (View Distance) | Proche | Les joueurs restent visibles, seul le décor lointain est simplifié |
| Résolution 3D | 100 % | Descends par paliers de 10 % seulement si les FPS sont trop bas |
| Textures, Maillages (Meshes) | Bas | Libère des ressources pour les images par seconde |

## Options avancées et son

- **NVIDIA Reflex Low Latency** : *Activé + Boost* avec une carte NVIDIA.
- **Afficher les FPS** : activé, pour comparer l'effet de chaque réglage.
- **Casque 3D** (son) : activé, pour mieux situer les bruits de pas.
- **Visualiser les effets sonores** : activé, un indicateur montre d'où viennent les sons.
- Laisse le **ray tracing** désactivé en partie compétitive : il coûte très cher en images par seconde.
